Architecture

      
Four gates between a photon and an answer.

      

        Every stage exists to throw work away. That is the entire latency and cost
        story — the model only runs on what survives.
      

    


    

      

        
01 / SENSE

        
Scene-change gate

        
A perceptual diff of downscaled grayscale plus a colour histogram. A
           still room sends nothing; the VLM fires only on real change, cutting
           calls by 10–100×.

        
      

      

        
02 / HEAR

        
Voice activity

        
Silero VAD segments the open mic into utterances, so speech-to-text
           runs on speech — never on the raw stream, never on silence.

        
      

      

        
03 / RECALL

        
Relevance gate

        
Long-term memory is searched only when the question needs it, and only
           facts above threshold reach the prompt — each stamped with its age so
           the past is never reported as the present.

        
      

      

        
04 / ANSWER

        
Single-pass stream

        
One call, tool schemas attached. If no tool is needed the tokens are
           already streaming — and the browser starts speaking sentence one while
           the rest is still arriving.
